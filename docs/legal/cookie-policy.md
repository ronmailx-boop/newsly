# מדיניות עוגיות (Cookies)

**עודכן לאחרונה:** [PLACEHOLDER - תאריך עדכון]

## 1. מהן עוגיות ואחסון מקומי

עוגיות (Cookies) ואחסון מקומי (Local Storage) הם קבצי טקסט קטנים הנשמרים
בדפדפן המכשיר בעת השימוש באתר, לצורך שמירת מידע והעדפות בין ביקורים.

## 2. שימוש בשירות זה

בגרסתו הנוכחית, השירות "Newsly" הוא אתר סטטי המוגש דרך GitHub Pages ואינו
משתמש בעוגיות מעקב (Tracking Cookies) או בכלי אנליטיקס של צד שלישי.

ייתכן שהשירות ישתמש באחסון מקומי (Local Storage) בדפדפן לצרכים טכניים
בלבד, כגון:
- שמירת המקור המועדף האחרון שסוננה לפיו התצוגה (טאב פעיל).
- שמירת העדפות תצוגה בסיסיות.

מידע זה **נשמר אך ורק במכשיר המשתמש**, אינו נשלח לשרת ואינו מזהה את
המשתמש באופן אישי.

## 3. עוגיות צד שלישי

נכון לכתיבת מסמך זה, השירות אינו טוען סקריפטים של אנליטיקס, פרסום או
מעקב מצדדים שלישיים. ככל שבעתיד יתווספו כלים כאמור (למשל לצורך ניתוח
שימוש), מסמך זה יעודכן בהתאם ויפורט מהן העוגיות, מטרתן ואפשרויות ניהול
ההסכמה.

## 4. ניהול העדפות

ניתן למחוק או לחסום אחסון מקומי ועוגיות באמצעות הגדרות הדפדפן בכל עת.
חסימה מלאה עשויה להשפיע על שמירת העדפות תצוגה בין ביקורים, אך לא תפגע
בהצגת החדשות עצמה.
